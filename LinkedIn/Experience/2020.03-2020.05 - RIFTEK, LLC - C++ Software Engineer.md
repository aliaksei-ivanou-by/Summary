## Highlights

• Developed a C++17/Qt R&D prototype that generated 3D models from the profile output of multiple standard 2D laser scanners.
• Implemented multi-sensor coordinate transformation, point-cloud assembly, filtering, downsampling, alignment, and surface reconstruction with the Point Cloud Library.
• Structured the processing pipeline into separately inspectable stages, making reconstruction faults attributable to a specific stage, sensor, or assumed sensor pose.
• Evaluated Point Cloud Library and Open3D on recorded multi-sensor datasets using real reconstruction behaviour rather than visual preference alone.
• Built a Qt desktop interface with 3D visualisation, per-sensor controls, per-stage inspection, and dataset replay so other engineers could evaluate feasibility independently.
• Contributed briefly to an exploratory medical 3D-scanning configuration combining two scanners in different planes for a prosthetics-related application.
