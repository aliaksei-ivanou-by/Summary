# Satellite and UAV Optical Imaging Software

## Project name

Satellite and UAV Optical Imaging Software

## Description

Image-processing algorithms and supporting software for Earth remote-sensing satellite payloads and a UAV optical system.

• Designed and implemented MATLAB algorithms for multi-detector frame stitching, radiometric matching, onboard compression, adaptive quantisation, and image-quality assessment.
• Developed an ADPCM-family lossy compression algorithm achieving a 3-4x ratio within a constrained onboard computation budget, followed by image-type prediction to improve quality at the same ratio.
• Automated linear-resolution assessment of flight-test imagery, replacing manual expert analysis with repeatable measurement.
• Developed UAV modules for debayering, stabilisation, image fusion, and format conversion, and calibrated IMU-to-camera alignment for frame-centre georeferencing.
• Designed a remote-sensing satellite reference database and web interface using Ruby on Rails and PostgreSQL.
• Operated the optical payload during more than 30 UAV test flights and participated in satellite flight tests and in-orbit operation control.

The work spanned algorithm design, numerical validation, instrument calibration, flight testing, and handover into constrained operational systems.
