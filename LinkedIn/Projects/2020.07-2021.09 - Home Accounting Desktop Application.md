# Home Accounting Desktop Application

## Project name

Home Accounting Desktop Application

## Description

Public C++20 desktop personal-finance application designed and implemented from a clean slate as a sole developer.

• Built a four-layer architecture separating domain models, SQLite data access, business logic, and an FLTK graphical interface.
• Implemented account, expense, income, and transfer workflows with multi-currency balances over a base currency.
• Created per-entity database and repository classes over the SQLite C API, with eight tables and explicit prepared-statement binding.
• Used GoogleTest from the first features and registered tests with CTest, allowing testability to guide the separation of interface, logic, and storage.
• Added structured logging with plog and a reproducible CMake build with pinned dependencies.
• Published the project on GitHub after 305 commits and 7 pull requests.

The application is a working demonstration of end-to-end C++ application design. Its documented limitation is that test coverage concentrated on model types while the most risk-sensitive multi-currency transaction logic remained insufficiently covered.
