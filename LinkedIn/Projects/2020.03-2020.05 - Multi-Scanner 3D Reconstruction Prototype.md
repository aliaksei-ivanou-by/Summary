# Multi-Scanner 3D Reconstruction Prototype

## Project name

Multi-Scanner 3D Reconstruction Prototype

## Description

C++17/Qt R&D prototype for generating 3D models from the output of several standard 2D laser profile scanners.

• Transformed per-sensor profiles from local coordinate systems into a shared frame and assembled them into a common point cloud.
• Implemented an inspectable PCL pipeline covering filtering, downsampling, outlier removal, normal estimation, alignment, and surface reconstruction.
• Evaluated Point Cloud Library and Open3D on recorded multi-sensor datasets.
• Built a Qt desktop interface with 3D visualisation, per-sensor controls, per-stage inspection, and dataset replay.
• Diagnosed reconstruction faults by separating individual sensor contributions and tracing errors to processing stages or assumed sensor poses.
• Contributed briefly to an exploratory two-scanner configuration intended for a prosthetics-related medical application.

The prototype demonstrated a software path from standard 2D scanner profiles to a usable 3D representation while preserving the measurement meaning of the source data.
