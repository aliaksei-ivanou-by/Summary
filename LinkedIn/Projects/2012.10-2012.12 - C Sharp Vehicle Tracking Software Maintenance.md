# C# Vehicle Tracking Software Maintenance

## Project name

C# Vehicle Tracking Software Maintenance

## Description

Part-time maintenance of an existing vehicle-tracking product at a GPS/GLONASS equipment manufacturer.

• Maintained and supported a C# application that consumed data from the manufacturer's telematics equipment.
• Reproduced reported behaviour and traced affected data through application logic and MySQL/PostgreSQL storage.
• Distinguished application defects from storage and retrieval problems that presented the same visible symptoms to users.
• Corrected defects in the layer that owned them, including database-related issues.

The three-month engagement applied prior field experience with installed tracking terminals to commercial software maintenance and cross-layer diagnosis.
