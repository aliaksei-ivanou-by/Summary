# C++ Foundations and Stroustrup Programming Exercises

## Project name

C++ Foundations and Stroustrup Programming Exercises

## Description

Systematic implementation of drills and exercises from Bjarne Stroustrup's Programming: Principles and Practice Using C++, Second Edition.

• Worked through language fundamentals, object-oriented programming, templates, the standard library, and the book's advanced material.
• Built the graphical exercises using FLTK.
• Focused particularly on the areas that differ most from MATLAB: object lifetime, ownership, value and reference semantics, RAII, templates, containers, and algorithms.
• Published the work as a public GitHub repository containing 141 commits.

The project supported the transition from MATLAB-based algorithm research to modern C++ as a primary engineering language and provided a reusable graphics layer later applied in the Home Accounting application.
