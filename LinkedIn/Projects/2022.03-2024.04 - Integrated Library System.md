# Integrated Library System

## Project name

Integrated Library System

## Description

Long-lived production platform supporting library staff workflows, patron and collection data, and external integrations.

• Shared responsibility for a large C89 backend, implementing features, fixing defects, and refactoring modules while preserving established workflows.
• Diagnosed failures across Scala APIs, C services, Java data services, PostgreSQL, and residual MySQL models.
• Investigated native failures on AWS-hosted Linux systems using service logs, SSH, gdb, and core dumps.
• Corrected defects involving memory initialisation, fixed-size character arrays, US daylight-saving-time behaviour, multilingual text processing, Japanese search and highlighting, and generated web/PDF output.
• Implemented a Swagger-documented Scala API request backed by C processing and a Java desktop-table field backed by C-side data.
• Built and validated changes through Jenkins, nightly and on-demand deployments, separate developer and QA environments, and mandatory cross-company review.
• Contributed to code review, onboarding, sprint demonstrations, and technical interviews.

The project continued without interruption through a promotion and an internal relocation from EPAM Systems Belarus to EPAM Systems Poland.
