# Embedded SIP Desk Phone Platform

## Project name

Embedded SIP Desk Phone Platform

## Description

Software platform for ARM64 SIP/IP desk phones combining a C++/Qt application, a customised Linphone SDK, Yocto-based Embedded Linux firmware, and Windows provisioning tooling.

• Developed C++17/Qt 5.15 functionality across asynchronous call and account state, contacts, BLF, audio/video calls, conferencing, device settings, and hardware integration.
• Implemented a registration watchdog and primary/backup SIP-server failover and failback in customised liblinphone, then integrated its APIs across application, diagnostics, settings, and provisioning paths.
• Refactored a stateful call subsystem towards explicit sessions, services, and Linphone adapters.
• Modernised a WinForms Autoprovisioning Manager from .NET Framework 4.8 to .NET 8 and implemented device discovery, configuration generation, DHCP/TFTP delivery, SIP realm probing, and AES-encrypted project persistence.
• Integrated application components, services, and assets into model-specific Yocto images and debugged behaviour on physical ARM64 phones.
• Worked on phone-side WebRTC/mediasoup integration and contributed in a limited capacity to the initial Node.js conferencing server.

The project required keeping SIP state, UI models, persisted configuration, firmware services, and hardware behaviour consistent across layer boundaries.
